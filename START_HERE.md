# С чего начать

Прочитайте этот файл, [AGENTS.md](AGENTS.md), [docs/NEXT-STEPS.md](docs/NEXT-STEPS.md),
затем `STORYBOARD.md` текущего ролика. Общие правила — [STYLE.md](STYLE.md) и
[STORY.md](STORY.md). Техническая карта — [docs/PIPELINE.md](docs/PIPELINE.md).

## Первый запуск

1. Установите Python 3.10+ и полный FFmpeg с ffprobe по [инструкции](docs/SETUP.md).
2. Установите `requirements.txt`, запустите `python -B engine/tools/doctor.py`.
3. Создайте ролик: `python -B engine/tools/new_project.py 01-topic`.
4. Заполните четыре раздела `projects/01-topic/STORYBOARD.md`: сюжет, визуальная
   концепция, цепочка анимаций, звук. Новый автор выбирает собственные референсы,
   композицию, палитру и персонажей. Готового авторского оформления здесь нет.
5. Подготовьте `script.py`, `config.py`, события и при необходимости данные подарков.
6. Получите пробные кадры командой `python -B projects/01-topic/render.py --frames 0,180,360`.
   В шаблоне до настройки стиля показан только нейтральный каркас.
7. Покажите хайлайты картинками. После слова автора **«собирай»**:
   `python -B engine/tools/build.py projects/01-topic --approved --name topic_v1`.
8. Проверьте декодированный результат, переходы и звук; запишите статус проверки.

## Что остаётся общим

1080×1920, 60 fps, H.264 yuv420p + AAC; чистый кадр как функция времени;
общие события для изображения и звука; полный прямой цикл Lottie;
читаемый текст; мягкие входы/выходы; обязательная центральная рекламная пауза
RubUp с полным оригинальным звуком. Точные правила — [docs/ADVERTISING.md](docs/ADVERTISING.md).

Подача, фон, графика, маскот, музыка, пространственные сцены, облака и зацикливание
выбираются для новой задачи. Они не считаются обязательным стилем.
Цены, курс, редкость и количество владельцев нельзя подставлять из памяти.

## Ключ и голос

Голос и модель по умолчанию выбраны автором: `7312c38557eb4fb384e3874e8e9cea67`,
модель `drama-3`. Озвучивайте через MCP-коннектор Fish Audio (`text_to_speech`),
а если его нет, через ключ. Если нет ни того, ни другого, спросите в чате:
«Подключите Fish Audio? Пока продолжу без дикторской озвучки». Не останавливайте сценарий, графику,
хайлайты и разрешённую сборку из-за отсутствия ключа. Не называйте такой результат
озвученным. Звук рекламного баннера остаётся.

Новый ключ вводится скрыто через `engine/tools/with_fish_key.py` либо задаётся
в окружении процесса. Ключ в комплект не включён. Ни один скрипт не ищет
учётные данные вне этого комплекта и не читает их из соседних проектов.

## Папки

| Путь | Назначение |
|---|---|
| `engine/` | нейтральные приёмы движения, текста, звука, рекламы и API |
| `engine/tools/` | новый проект, проверки, озвучка, кадры, сборка |
| `templates/project/` | стартовый контракт одного ролика |
| `projects/` | новые работы; изначально пусто |
| `input/` | баннер, шрифт; свои материалы добавляются отдельно |
| `.agents/skills/telegram-video/` | переносимый навык производства и его методические модули |
| `.claude/skills/telegram-video/` | вход в тот же навык для Claude |
| `docs/` | установка, конвейер, данные, реклама, текущий статус |

Результаты и кэш появятся только после локального запуска. Они исключены из Git.
