# Обязательная реклама RubUp

Используется только `input/video/RubUP Gifts banner.mov` — актуальный прозрачный
баннер со своей звуковой дорожкой. Включать полностью, без обрезки начала/конца,
подмены звука, наложенного текста и перекрытия другими героями.

- В каждом ролике — одна вставка примерно в середине. Для длинного видео —
  одна в середине каждой минуты. Планируйте паузу речи заранее.
- Основное содержание и его звук плавно останавливаются, баннер проигрывается,
  затем содержание плавно продолжается. События во время рекламы не уходят вперёд.
- Баннер **по центру кадра**, в стандартном формате центр `(540, 960)`.
  Ширина 1080 px, пропорции сохранены; высота примерно 567 px, площадь около 30%.
  Нижняя граница требования — 25% кадра, не угол экрана.
- Дополнительная прозрачность не выше 8%; код сохраняет исходную альфу без
  искусственного ослабления непрозрачных частей.
- Исходная скорость 1,0×, допустимое ускорение максимум **1,1×**.
  По умолчанию 1,1×; звук ускоряется через atempo без повышения тона.
- Фон на время паузы затемняется на 20%, мягкое торможение/возобновление 0,4 с.
  Маскот и сторонние SFX для рекламной вставки не нужны.

`BR = banner.Breaks([content_stop], cy=960, speed=1.1)` одинаков в `render.py` и
`audio.py`. Изображение: `BR.render(render_at, output_time)`; звук: `BR.audio(mix, SR)`;
итоговая длительность: `BR.out_dur(DUR)`.
Звук баннера сохраняется и при отсутствии дикторской озвучки.

Эти параметры — требования комплекта. При новых условиях рекламодателя сначала
обновите этот документ и код, затем проверьте пробную вставку.
