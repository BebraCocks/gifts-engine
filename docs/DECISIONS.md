# Решения

## 2026-11-02 · Независимый старт для нового автора

Основа — Telegram-видео и обязательный центральный RubUp. Переносится техника:
детерминированная анимация, полный цикл подарков, API, типографика, синхронизация,
звук, реклама, раскадровка, показ хайлайтов и проверка результата.
Оформление определяется новыми референсами и решениями автора.

Единственные включённые медиа — актуальный баннер и SF Pro Text.
Ключ Fish Audio и голос задаёт новый владелец. Без них работа продолжается
без дикторской озвучки. Кэш, установленное окружение и история аккаунта не нужны.
Сведения об оборудовании, абсолютные личные пути и персональные настройки
не входят в комплект. Код использует пути относительно корня и PATH.

Новые решения записывать здесь с датой и причиной.

## 2026-11-04 · 02-resistance-dog: 3D через Blender на CPU

Автор попросил 3D-сцены и движение камеры по своему референсу. GPU нет, поэтому Blender 5.2 (bpy)
EEVEE через llvmpipe: 540×960, 2 сэмпла (на глаз не отличимо от 6), апскейл до 1080×1920;
2D-слои (подарки, текст) — в полном разрешении. Анимация ключуется по кадрам — работает motion blur.
Озвучка: Fish Audio `drama-3` (неверное имя модели API молча заменяет на s2.1-pro — проверять на слух).
Тайминг слов — ASR Fish Audio (`engine/tools/fish_asr.py`), т.к. Hugging Face закрыт сетью сессии.
`banner.Breaks.audio` векторизован (`content_t_array`), результат идентичен поэлементному.

## 2026-11-03 · Fish Audio через MCP

API-ключ автора работает только с бесплатной моделью (`s2.1-pro-free`): API-кредит 0,
а подписка Pro на API не распространяется (ответ сервиса: «API credit is separate from
your subscription credits»). Добавлен официальный MCP-сервер `https://api.fish.audio/mcp`
(`.mcp.json`), который входит в аккаунт и расходует кредиты подписки. Ключ не нужен.

## 2026-11-05 · SFX по умолчанию — пак Botanica V4

Автор передал пак Botanica V4 (Google Диск, 4 RAR-тома, 637 звуков) и попросил сделать
его SFX по умолчанию. Пак лежит в `input/sfx/botanica-v4/` в Git. Он переведён в FLAC
48 кГц / 24 бит: 374 МБ вместо 1,5 ГБ WAV, а файлы меньше лимита GitHub в 100 МБ.
Анализатор `engine/tools/sfx_catalog.py` строит каталог с ролями и тегами по огибающей
и спектру. Модуль `engine/sfxkit.py` выбирает звуки так, чтобы они не повторялись внутри
ролика и между роликами (история в `docs/SFX-USAGE.json`), и добавляет микровариации.
Причина: автор не хочет, чтобы ролики звучали одинаково, а серия щелчков звучала как
«стрельба автомата». Вместе с хайлайтами автор получает файлами SFX-дорожку,
полный микс и список времён. Правила — `docs/SFX.md`. Синтез SFX кодом, как
в ранних роликах, теперь используется, только если в паке нет нужного звука.

## 2026-11-05 · Без Whisper, проверка озвучки через Fish Audio

Автор не хочет, чтобы в сессиях скачивались лишние пакеты и модели. `faster-whisper` удалён
из `requirements-optional.txt`, скрипт `whisper_asr.py` удалён. Текст дубля проверяется
через MCP Fish Audio (`speech_to_text`, `flash`) по ссылке на результат генерации.
Время слов даёт `fish_asr.py` (MCP возвращает текст без времени).

## 2026-11-05 · Fish Audio только через коннектор claude.ai

`.mcp.json` и `.claude/settings.json` удалены. Проектный MCP-сервер в облачной сессии
не авторизуется и выглядел как «Fish Audio не подключён», хотя коннектор claude.ai
работал. Теперь подключение одно — коннектор аккаунта.

## 2026-11-05 · 04-calendar-craft «Первый крафт»

Бриф автора: 78–80 с с RubUp, 2D-стиль, до двух 3D-сцен, персонажи Алексей и Михаил со своими голосами
Fish Audio (`ce15cf1a…`, `b517ea60…`), диктор — голос по умолчанию. Решения: персонажи и фоны рисуются
кодом (`chars.py`, `sets.py`) — нужны десятки поз и мимика с синхронизацией рта по громкости дубля;
генерация картинок не даёт стабильной идентичности героя между позами. 3D — перспективная проекция в
numpy (хранилище 57 крафтовых календарей; Celestial Map на фоне Black), без Blender. Реклама — через
стоп-кадр после разбитого телефона и подводку диктора. Речь не ускорялась: текст сокращён под длительность.
Звука огня в Botanica V4 нет — синтезирован в `audio.py`.
