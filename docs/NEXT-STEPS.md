# Текущее состояние — 2026-11-02

Комплект подготовлен для нового автора. Рабочих роликов, выбранного голоса,
референсов и согласованного визуального стиля ещё нет.

1. Установить зависимости и FFmpeg по `docs/SETUP.md`.
2. Назвать тему и предоставить собственные референсы либо описать желаемый стиль.
3. Создать новый проект и заполнить четыре раздела раскадровки.
4. При желании добавить свой ключ Fish Audio и выбрать свой голос. До этого
   продолжать без диктора, сохраняя звук рекламного баннера.
5. Показать хайлайты картинками, дождаться «собирай», собрать и проверить результат.

Проверки комплекта и их границы описаны в [VALIDATION.md](VALIDATION.md).
После каждой работы обновлять этот файл и статус раскадровки.
