# Установка в новом окружении

Нужны Python 3.10+, FFmpeg и ffprobe с кодеками libx264 и AAC.
Установите их обычным способом для своей системы и добавьте в PATH.
Альтернатива PATH — переменные `FFMPEG` и `FFPROBE` с путями к установленным программам.
Встроенного каталога программ или привязки к оборудованию нет. Базовая сборка работает на CPU.

Из корня комплекта:

```sh
python -m venv .venv
```

Активируйте окружение: Windows PowerShell — `.venv\Scripts\Activate.ps1`,
Linux/macOS — `source .venv/bin/activate`. Затем:

```sh
python -m pip install -r requirements.txt
python -B engine/tools/doctor.py
python -B engine/tools/verify_project.py --distribution
python -B engine/tools/new_project.py 01-topic
```

PyAV читает прозрачность HEVC рекламного баннера. Обычное декодирование баннера
через произвольную сборку FFmpeg может потерять альфу, поэтому используйте `engine/banner.py`.
Версии зависимостей заданы диапазонами; новый чистый venv требует фактической
установки и проверки. Нет необходимости переносить установленное окружение.

## Озвучка новым аккаунтом

Ключ не нужен для разработки и сборки без диктора. Новый автор выбирает голос
в Fish Audio самостоятельно. Предустановленного идентификатора голоса нет.
После выбора идентификатора:

```sh
python -B engine/tools/with_fish_key.py engine/tools/tts_takes.py projects/01-topic --voice VOICE_ID --takes 2
```

Команда скрыто запрашивает новый ключ, передаёт его только дочернему процессу
и ничего не сохраняет в файл настроек. `VOICE_ID` заменяется своим выбором.
На пустом вводе команда сообщает об отсутствии озвучки и завершает работу успешно.
Прослушайте дубли и скопируйте выбранные в `voice/L01.wav`, `voice/L02.wav`…
Существующие дубли не перезаписываются. Для явного режима без голоса:
`WITHOUT_NARRATION = True` в конфигурации ролика.

`FISH_API_KEY`, `FISH_VOICE`, `FISH_TTS_MODEL` можно задавать в окружении процесса.
Без них используются голос `7312c38557eb4fb384e3874e8e9cea67` и модель `drama-3`
(`DEFAULT_VOICE`, `DEFAULT_MODEL` в `engine/tools/fish_tts.py`).
`.env.example` — только справочник; автоматического чтения `.env` нет.
Никаких ключей из соседних каталогов или настроек другого аккаунта код не ищет.
Проверка нового ключа: `with_fish_key.py engine/tools/doctor.py --online`.

Документация API: [Fish Audio](https://docs.fish.audio/features/text-to-speech).
Параметры тарифа и доступные модели проверяются в аккаунте; бесплатность не обещается.

## Дополнительные инструменты

`python -m pip install -r requirements-optional.txt` добавит графики аудио и
локальный faster-whisper. Для проверки дикции можно установить модель самостоятельно;
ни веса модели, ни её кэш сюда не входят. Распознанный текст — вспомогательная
проверка, прослушивание он не заменяет.

Навык автоматически обнаруживается поддерживающими `.agents/skills` агентами.
Для Claude есть вход в `.claude/skills`; другой нейросети достаточно прочитать
`AGENTS.md` и указанный в нём `SKILL.md`. Дополнительных плагинов проект не требует.

## Fish Audio через MCP (вход в аккаунт, без API-ключа)

Добавлено 2026-11-03. Официальный MCP-сервер Fish Audio — `https://api.fish.audio/mcp`
(streamable HTTP, вход через OAuth в браузере). По описанию Fish Audio он тратит
кредиты **подписки**, как сайт, а не API-кредит. Ключ не нужен и не хранится.

- **Claude Code на своём компьютере:** `.mcp.json` в корне уже содержит сервер
  `fish-audio`, `.claude/settings.json` разрешает его. Откройте проект, введите `/mcp`,
  выберите `fish-audio` и войдите в аккаунт Fish Audio. Альтернатива вручную:
  `claude mcp add --transport http fish-audio https://api.fish.audio/mcp`.
- **Облачные сессии claude.ai / телефон:** добавьте пользовательский коннектор
  `https://api.fish.audio/mcp` на https://claude.ai/customize/connectors, войдите в
  Fish Audio и начните **новую** сессию — коннекторы читаются при старте сессии.
- Сгенерированный звук сервер отдаёт ссылкой; если домен ссылки закрыт сетевыми
  правилами окружения, его нужно разрешить, чтобы скачать файл в `voice/`.
- Голос автора: `7312c38557eb4fb384e3874e8e9cea67`. Выбранные дубли кладутся в
  `voice/L01.wav…`, как и при работе через API.
