# Звуковые эффекты (SFX)

Решение автора от 2026-11-05: пак **Botanica V4** — библиотека SFX по умолчанию для всех
новых роликов. Синтезировать эффекты кодом или брать звуки из других источников можно,
только если в паке нет подходящего звука или автор попросил иначе. Причину запишите
в раскадровку.

## Где лежит

| Путь | Что это |
|---|---|
| `input/sfx/botanica-v4/<категория>/*.flac` | 637 звуков: FLAC 48 кГц / 24 бит, латинские имена |
| `input/sfx/catalog.json` | результат анализа: роль, длительность, атака, спектр, удары, теги |
| `input/sfx/CATALOG.md` | тот же каталог таблицами для чтения |
| `input/sfx/SOURCE.md` | происхождение пака и соответствие имён оригиналу |
| `engine/tools/sfx_catalog.py` | анализатор, просмотр, листы волн и спектров, прослушивание роли |
| `engine/sfxkit.py` | выбор и размещение звуков в миксе, чтобы звуки не повторялись |
| `docs/SFX-USAGE.json` | какие звуки взял каждый ролик; новые ролики выбирают другие |

Исходный пак — 4 RAR-тома, 1,5 ГБ WAV до 96 кГц / 32 бит float. Для видео (AAC 48 кГц)
его перевели в FLAC 48 кГц / 24 бит: для итогового звука это без потерь, а в Git он
занимает в несколько раз меньше. Если пик файла был выше 0 dBFS, его опустили без
клиппинга; поправка записана в `SOURCE.md`.

## Как понять, что внутри

```sh
python -B engine/tools/sfx_catalog.py                   # пересобрать каталог после добавления файлов
python -B engine/tools/sfx_catalog.py --show whoosh     # таблица роли или части имени
python -B engine/tools/sfx_catalog.py --sheet click     # волна и спектрограмма каждого звука -> .cache/sfx/
python -B engine/tools/sfx_catalog.py --audition click  # все варианты роли подряд в одном MP3 + список времён
```

Что измеряется, описано в начале скрипта: длительность звучания, атака, место пика,
хвост, отдельные удары в файле, число транзиентов, центр спектра (тёмный, нейтральный
или яркий звук), доли низа, середины, верха и «воздуха», шумность или тональность,
рост или спад громкости и высоты, ширина стерео. По числам скрипт ставит теги:
`micro/short/medium/long/bed`, `dark/neutral/bright`, `noisy/tonal`, `sharp/swell`,
`rising/decaying`, `pitch-up/pitch-down`, `multi/burst`, `bassy`, `wide/mono`.

Числа помогают отобрать кандидатов и найти дефекты. Подходит ли звук, решает
прослушивание. Перед выбором звука для важного акцента смотрите `--sheet`
и слушайте `--audition`.

Основные роли (полный список с количеством — `CATALOG.md`):

| Действие на экране | Роли |
|---|---|
| нажатие, выбор, появление плашки | `click`, `select`, `select-soft`, `popup`, `pop` |
| правильно / ошибка | `confirm`, `error` |
| перелёт, смена сцены | `whoosh`, `whoosh-short`, `whoosh-deep`, `whoosh-organic`, `sparkle-whoosh`, `cartoon-move` |
| удар, приземление, раскрытие | `impact`, `sub-drop`, `riser-hit`, `cartoon-hit` |
| нарастание к событию / спад | `riser`, `power-up`, `downlifter`, `power-down`, `spinback` |
| блеск, редкость, NFT | `sparkle`, `granular-combo`, `granular-move` |
| цифры, счётчики, списки | `counter`, `list`, `scan` |
| текст, интерфейс, сбой | `typing`, `key-enter`, `key-backspace`, `glitch`, `glitch-text`, `glitch-texture` |
| материал | `paper`, `coin`, `shutter`, `foley`, `flip`, `stretch`, `transform` |
| характер, юмор | `boing`, `cartoon`, `voice` |
| фон | `ambience`, `bed`, `music-transition` |

## Правила разнообразия

Это главное требование автора. Ролики не должны звучать одинаково, а серия
одинаковых действий не должна звучать как очередь из автомата.

1. Звуки ставятся только через `sfxkit.Kit` в `audio.py` ролика. Файлы напрямую
   (`sound.SFX`, абсолютные пути) не берите, иначе не работают правила 2–4.
2. **Внутри ролика.** Варианты роли выбираются из перемешанного набора без повторов, пока
   набор не закончится, и никогда не идут два раза подряд. Если в одном файле несколько
   щелчков, каждый щелчок считается отдельным вариантом. Четыре щелчка подряд —
   четыре разных щелчка.
3. **Между роликами.** `kit.save()` записывает в `docs/SFX-USAGE.json`, какие звуки
   взял ролик. Следующий ролик ставит эти звуки в конец очереди. Сильнее всего
   учитываются три последних ролика. Повтор допустим, только когда роль исчерпана.
   Файл истории коммитится вместе с роликом.
4. **Микровариации.** Каждый экземпляр звука получает ±1 дБ громкости
   и ±0,3 полутона высоты. Если вариант всё же повторяется в пределах 4 с, его высота
   сдвигается на 1–2 полутона. Для голосов, фонов и мотивов вариации отключены
   (`vary=False` или `key=`).
5. **Намеренный повтор.** Если один звук должен быть узнаваемым мотивом (например,
   «удар» каждой новой модели), используйте `key='имя'`. Мотив записывается
   в раскадровку.
6. Выбор зависит от имени папки ролика, поэтому повторная сборка звучит так же.
   Чтобы послушать другой набор, передайте `Kit(HERE, seed=…)` и запишите seed.
7. Одна роль не обязана звучать на каждом стыке. Подбирайте роль по действию
   и материалу, а не по привычке. Тишина тоже бывает акцентом.

## Сведение

- `kit.add(fx, роль, t, gain_db=…, pan=…, align=…)`, время — время содержания из `events.py`.
  `align='peak'` ставит самый громкий момент на событие (whoosh на склейку),
  `align='end'` заканчивает звук на событии (riser перед ударом), `fit=` обрезает фон.
- Все варианты заранее выровнены к −20 dBFS RMS с пиком не выше −1 dBFS, поэтому
  `gain_db` у разных вариантов одной роли означает одну и ту же громкость.
  Ориентиры: интерфейсные щелчки от −18 до −12 дБ, whoosh от −16 до −10 дБ,
  удары от −12 до −6 дБ, фон от −30 до −24 дБ. Окончательную громкость
  определяет прослушивание.
- Под речью SFX приглушаются (sidechain от огибающей голоса, как в шаблоне).
- RubUp: стороннего SFX внутри рекламной вставки нет, звук баннера оригинальный.

## Что показывать автору

Каждый раз вместе с хайлайтами (картинками) отправляйте файлы из `build/review/`:

- `sfx_only.mp3` — только SFX, по времени готового видео (с паузой под RubUp);
- `mix.mp3` — полный микс: голос, SFX, баннер;
- `sfx_cues.txt` — список «секунда → роль → файл#удар → метка».

Автор может сказать «на 12,4 с не то»: найдите строку в `sfx_cues.txt`, замените роль,
фильтр или `key`, пересоберите `audio.py` и отправьте файлы снова.
Технический анализ не заменяет прослушивание. В отчёте честно пишите, что слушал автор,
а что проверено только по числам.

## Добавить новый пак

Положите пак в `input/sfx/<имя-пака>/` с латинскими именами. При необходимости добавьте
правила ролей в `ROLE_RULES` скрипта `sfx_catalog.py`, затем выполните
`python -B engine/tools/sfx_catalog.py` и закоммитьте пак вместе с каталогом.
Файлы больше 100 МБ GitHub не принимает: длинные фоны конвертируйте во FLAC 48 кГц.
