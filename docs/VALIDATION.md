# Проверки комплекта — 2026-11-02

Комплект проверен локально и в отдельной копии с другим корнем каталога.

- Все Python-файлы компилируются, основные модули импортируются, локальные
  Markdown-ссылки существуют. Оба входа в навык проходят проверку формата SKILL.md.
- Проверены создание нового проекта, отсутствие запроса к Fish Audio без нового
  ключа, стопкадры, звуковой микс без диктора и запреты сборки без разрешения/стиля.
- Проверены кириллица во всех пяти шрифтах, центрирование текста, субтитры,
  композиция спрайтов, живой JSON/TGS и полный прямой цикл.
- Настоящий баннер декодируется в 366 кадров / 60 fps. Проверены прозрачность,
  центр, площадь больше 25%, монотонная временная карта, остановка/возобновление
  содержания, запрет скорости вне 1,0–1,1× и звук рекламы при отсутствии диктора.
  Центральная вставка дополнительно осмотрена на пробном кадре.
- Публичный API фактически вернул модели подарка; одна свежая анимация скачана
  и отрисована в отдельном временном каталоге. Файлы теста в комплект не включены.
- Проверен точный состав медиа: один актуальный баннер и пять OTF.
  Проверены текст, известные персональные маркеры, 160 записей метаданных шрифтов
  и метаданные контейнера баннера; персональных сведений не обнаружено.
- Ключевые каталоги/файлы секретов не читались и не копировались. В поставке
  отсутствуют кэш, история аккаунта, готовые ролики, референсные медиа, модели,
  музыка, SFX, дубли голоса и сведения об исходном оборудовании.

Полный MP4 не собирался: это подготовка основы, собственного нового ролика пока
нет. Звук не прослушивался, движение в реальном времени не оценивалось.
Платная генерация Fish Audio, чистая установка зависимостей и запуск в другой
операционной системе не выполнялись. Их нельзя считать подтверждёнными этими проверками.

Команды для повторения:

```sh
python -B engine/tools/doctor.py
python -B engine/tools/verify_project.py
python -B engine/tools/verify_project.py --distribution
python -B engine/tools/smoke_test.py
python -B engine/tools/smoke_test.py --online-gifts
```

`--online-gifts` использует только публичный API; ключ Fish Audio не требуется.
Полную сборку MP4 эта проверка не запускает. `--distribution` проверяет исходный
неизменённый комплект по SHA-256-манифесту. После добавления своих проектов
используйте обычную проверку без этого флага.
