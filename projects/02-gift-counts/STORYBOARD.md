# 02 · Графы в подарках Telegram

## 1. Сюжет

**Тема.** Модели подарков Telegram, связанные с графами (Count / Earl) и графом Дракулой.
Автор не уточнил, «граф» или «Гринч»; выбран «граф» (рекомендация, 2026-11-04).
**Зритель.** Владельцы и покупатели подарков, любители коллекционных моделей.
**Длительность.** 52,4 с содержания + RubUp 6,1 с = **58,5 с** (цель 58–59 с).
**Главная мысль.** «Графов» в подарках 12, но настоящий граф среди них один: Earl Grey.
У каждого героя есть вердикт: пародия, пират, вымысел, настоящий. После просмотра зритель
знает, кто есть кто, и запоминает пару фактов для спора. Это и есть его польза.
**Режим.** Без дикторской озвучки (ключа Fish Audio нет): весь смысл передаёт текст на экране.

## 2. Визуальная концепция

Собственное решение (референсов от автора нет): **«Ночная галерея графа»** — 3D-коридор замка.

- Пространство: длинная галерея 6 × 5,2 м, пол — тёмный мрамор в шахматку с бликами свечей,
  стены — сливовый дамаск, панели с золотой рейкой, балки потолка, туман по глубине.
  Сцена рассчитывается трассировкой лучей по кадру (`gallery.py`), портреты — перспективные плоскости.
- Герои: каждый подарок — живой портрет в золотой раме; Lottie играет внутри холста.
  Холст окрашен фоном Telegram (центр → край): Purple, Burgundy, Midnight Blue, Black, Satin Gold.
  Фоны выбраны для композиции, это не конкретные экземпляры подарков.
- 7 портретов Dracula висят в начале коридора (видны в хуке), 4 героя — на стенах по очереди,
  Earl Grey — в торце галереи, крупнее остальных.
- Свет: бра со свечами между портретами (мерцание по seed), над героем загорается подсветка.
- Палитра: почти чёрный сливовый, пергамент (243, 230, 200), золото (217, 164, 65), кровь (190, 24, 48).
- Типографика: SF Pro Text Heavy / Semibold / Medium. Заголовок вверху (y ≈ 200–330),
  факты внизу на тёмной плашке (y ≈ 1380–1650), портрет между ними. Баннер RubUp по центру.
- Вердикт — штамп, который «ударяет» по холсту в 3D и остаётся на нём до конца.

## 4. Звук

- Голос: нет (ключа Fish Audio нет). Звук баннера RubUp сохраняется полностью.
- Синтезированный звук (`audio.py`, без внешних файлов): тёмный дрон ре минор, свист пролёта
  на хуке и разворотах, глухой удар штампа, щелчок подсветки, колокольчик на Earl Grey и в финале.
  На время рекламы содержание плавно затихает вместе с картинкой.
- Микс на слух не проверен: только технический анализ.
