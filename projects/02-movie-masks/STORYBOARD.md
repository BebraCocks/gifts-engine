# 02 · Маски из кино

## 1. Сюжет

Тема: пять масок коллекции Myth Mask, отсылающих к самым известным фильмам и
персонажам. Зритель — широкая аудитория Telegram, знать подарки не обязательно.
Главная мысль: маска превращает человека в персонажа, и пять самых узнаваемых
киномасок теперь существуют как подарки. **Без диктора** (ключа Fish Audio нет,
решение автора 2026-11-03): смысл несёт экранный текст по одному слову, как в
референсе; времена чтения оценочные (~2,8 слова/с).

Длительность: автор попросил 8–10 с на маску (≈ 8,2 с в итоге) и ролик 58–59 с:
52,4 с содержания + RubUp 6,12 с = 58,5 с.

Данные: api.changes.tg, получено 2026-11-03. Myth Mask вышла 2025-10-31, улучшение
открыто 2026-10-31 по API (вторым источником не подтверждено, в ролике не упоминаем).
Цены, тираж и владельцы не используются (не проверены).

## 2. Визуальная концепция

### Референс автора (получен 2026-11-03)

Файл `VID_20261103_191808_785.mp4` из загрузки автора: 57,7 с, 576×1024, 30 fps.
Просмотрены листы кадров по 2 fps и плотные выборки по 6 fps (3–7 с, 8,5–12,5 с, 41–45 с);
звук не анализировался. Файл не входит в ролик, переносятся только принципы.

Наблюдалось:
- Стилизованный 3D-мир (каньон, рельсы, вокзал, мост); плоские 2D-персонажи
  стоят в нём как карточки с тенью.
- Камера всё время в движении: проезд низко над рельсами, пролёт вдоль стены каньона,
  кран вниз, медленный наезд на героев. Статичных планов почти нет.
- Переходы: камера разгоняется с сильным смазом и «влетает» в следующую локацию
  (пустыня → вокзал); короткий наплыв (~0,2 с) поверх движения камеры; движение
  переносится объектом (кран, рельсы).
- Подписи: одно слово за раз, прописные с чёрной обводкой, по центру ниже середины,
  цвет слова меняется (жёлтый, голубой, зелёный, белый).

Переносим: 3D-пространство с движущейся камерой, маска — 2D-карточка внутри сцены,
переход полётом камеры со смазом, у каждой маски своя локация, слова по одному.

### Локации (в духе места действия, свои упрощённые сцены, без кадров из фильмов)

| Блок | Локация | Камера и переход дальше |
|---|---|---|
| Хук | гримёрка за кулисами: зеркало с лампами, силуэт | наезд в зеркало → полёт сквозь него |
| Ghostface | ночной пригород (Вудсборо, «Крик»): дом с крыльцом, газон, свет в окне | проезд по газону к крыльцу → нырок в тёмное окно |
| Anonymous | ночной Лондон: силуэт парламента и часовой башни, Темза, фейерверки 5 ноября | пролёт над рекой, розы летят в камеру → сквозь розы |
| Bella Ciao | Мадрид, монетный двор: колоннада, внутри печатный цех, летят купюры | облёт колонн → сквозь дождь купюр |
| Arthur Fool | Готэм-Нью-Йорк: длинная уличная лестница между домами («лестница Джокера») | спуск камеры по лестнице → взлёт вверх по фасаду |
| Dark Knight | крыша небоскрёба ночью, дождь, бэт-сигнал в облаках | кран вверх к сигналу |
| Финал | сцена театра, пять масок в ряд | отъезд |

Технически: three.js в headless Chromium (WebGL2 через SwiftShader проверен
2026-11-03), геометрия и текстуры строятся в коде. Сайты бесплатных 3D-ассетов
(Poly Haven, Kenney, Quaternius) из среды недоступны. Детализация будет проще,
чем в референсе. Сначала короткая проба: гримёрка → переход → пригород.

### Оформление (утверждено автором по пробе, `STYLE_READY = True`)

- **Сцена:** тёмная театральная коробка, один верхний луч. Маска — единственный
  яркий объект. Фон при каждой маске окрашивается радиальным градиентом реального
  фона Myth Mask (`centerColor` → `edgeColor`), края уходят в почти чёрный.
- **Цвета масок:** Ghostface — Black, Anonymous — Burgundy, Bella Ciao — Fire Engine,
  Arthur Fool — Malachite, Dark Knight — Midnight Blue. Общий тёмный фон #0B0B0F.
- **Типографика:** SF Pro Text. Заголовок фильма — Semibold, прописные, разрядка,
  как титр фильма. Факт — Regular, 2–3 строки. Плашка «модель · %» — мелко у низа маски.
- **Силуэт в хуке:** процедурная голова с шеей, тёмно-серая, контровой свет.
- **Смена маски:** переворот по оси Y (масштаб X → 0 → 1) с коротким бликом на ребре.

## 3. Цепочка анимаций

Код: `scene3d/` (локации `loc_*.js`, монтаж `main.js`), подписи и реклама — `render.py`,
времена — `script.py`/`timeline.py`. Камера в каждой локации — кривая Эрмита по ключам,
в точках остановки взгляда скорость нулевая (без проскока цели). Смаз: 1–12 подкадров
по скорости камеры, выдержка ½ кадра. Переходы: ускорение камеры + скрещивание 0,2 с.

| Переход (содержание) | Носитель движения |
|---|---|
| 4,85–6,65 | маска срывается с лица, камера обходит голову и пролетает сквозь зеркало |
| 15,0–15,52 | рывок в тёмное окно второго этажа → ночное небо Лондона |
| 24,0–24,55 | лепестки роз летят в камеру → купюры Мадрида |
| 32,0–32,65 | порыв купюр закрывает кадр → лестница |
| 40,2–40,75 | рывок камеры вверх по фасаду → взгляд вверх на бэт-сигнал |
| 48,3–48,95 | полёт в луч прожектора → прожектор сцены |

Lottie: 5 масок, у всех 180 кадров, 60 fps, полный прямой цикл (prep_masks.py проверяет альфу).
Сдвиг фазы: Ghostface +0,9 с (кровь на «МАНЬЯК»), Dark Knight +1,5 с.

## 4. Звук

Голос: нет — ключа Fish Audio в сессии нет (проверено 2026-11-03, `FISH_API_KEY` отсутствует).
Музыки нет. Саунд-дизайн синтезирован в `audio.py` по той же карте событий: лампы,
нарастание и удар посадки маски, удары смен, свист переходов, звон стекла, сверчки, река,
удар часов, фейерверки (времена из 3D), «сердце» перед рекламой, шелест купюр, гул улиц,
шаги, дождь и гром, щелчки прожекторов, занавес. Звук баннера RubUp — полностью,
1,1× через atempo; содержание плавно стихает перед паузой и возвращается после.
