# 02 · Pepe — коллекция NFT-подарков

## 1. Сюжет

**Версия 4 (2026-11-03), правки автора:** цену модели не называть. Gram переводить
в рубли и говорить, что на эту сумму можно купить (машину и т. п.), показывать
покупку в кадре. Персонаж — собака **Resistance Dog** (оригинал подарка, картинка
от автора; в API есть живая Lottie, 3 с). Рта у неё нет: говорит закадровый голос,
собака изображает слова. Собака садится в купленный транспорт и едет в следующую
локацию.

**Формат:** 58,3 с = 52,16 с содержания + RubUp 6,12 с (по тестовому голосу v4,
`s2.1-pro-free`, скорость 1,05; финальный голос — через MCP после авторизации).

## 2. Визуальная концепция

Пять локаций, по которым собака едет на купленном транспорте:
болото → ночная улица города → канализация → космос → кухня. Транспорт рисуется
своими стилизованными спрайтами без логотипов (силуэт «семёрки», самокат, «Ока»,
жёлтое такси с шашечками). Собака — Lottie Resistance Dog в окне машины / на самокате.
Цифра в рублях появляется в кадре коротко («≈ 87 000 ₽ = старые «Жигули»»),
диктор её не произносит.
