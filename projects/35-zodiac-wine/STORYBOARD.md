# 35 · Гороскоп из телеги (Spiced Wine, зодиакальные модели)

## 1. Сюжет

**Задача автора (чат 2026-11-08).** «Гороскоп есть даже в телеге! Узнай, подходят ли они твоему знаку зодиака»
(черновик автора, доработан). Подробный хук в начале, 4 кружки из зодиакальной серии, гороскоп на каждую, красиво;
байт на комментарии в конце; 58–60 с с RubUp; кружки показывать крупнее (мелкие детали).
Голос — ссылка автора `fish.audio/m/48ec28a4…` («Энергичный Рассказчик»), drama-3, эмоции и интонации тегами.

**Факты (api.changes.tg, 2026-11-08).** Подарок Spiced Wine: 100 моделей; 12 из них — знаки зодиака, у каждой 0,8%.
В модели: глиф знака на жетоне и созвездие на напитке (видны в начале 3-секундного цикла, дальше кружка поворачивается).
Цены и «шт.» — скриншот автора 2026-11-08 (TON): Scorpio Sling 4,98 / 886 шт., Leonade 5 / 850, Vin Virgo 4,59 / 892,
Aquarium 4,69 / 895. **Гороскопы шуточные, написаны для ролика** (не из источника).

**Выбор четырёх — по одной на стихию:** Скорпион (вода; сейчас его сезон), Лев (огонь), Дева (земля), Водолей (воздух).

**Длительность.** 53,19 с содержания + RubUp ≈ 6,1 с = **59,3 с**. Реклама после второго знака (29,8 с), перед ней тизер.

## 2. Визуальная концепция

Ночное небо (11, 12, 30), неподвижные звёзды + 46 мерцающих, без градиентов (свечение — с дизерингом).
Акцент хука и призывов — золото (246, 206, 120); у каждого знака свой цвет = цвет напитка.
Кружка-герой Lottie 720 px (кружка ≈ 650 px в высоту), сдвиг на −4,7% ширины: в кадре Lottie кружка правее центра.
Глифы знаков — DejaVu Sans Bold (в SF Pro их нет). Созвездия стилизованы по реальным фигурам.

## 4. Звук

- Голос drama-3 `48ec28a4…`, 1,15× (atempo, тон не меняется). Дубли — `takes.json`.
- Музыка `music.py` (кодом): ночной фон, ля минор Am(add9) – Fmaj7 – C – Gsus, 76 BPM, пэд + челеста;
  саб-подъём на посадке каждой кружки, звонкий пробег на каждом «прогнозе».
- SFX Botanica через `sfxkit` (список и времена — `build/review/sfx_cues.txt`): колесо — sparkle-whoosh, «12» — sparkle,
  «4» — select, плашка — pop, полёт/падение — whoosh / whoosh-organic / whoosh-short, посадка — impact (только `hit-impact`,
  глитч-удар исключён), созвездие — granular-move, «ПРОГНОЗ» — один popup (мотив, `key='forecast'`), искры — sparkle,
  тизер — popup, финал — sparkle-whoosh + confirm, комментарии — pop. Во время RubUp своих SFX нет.
