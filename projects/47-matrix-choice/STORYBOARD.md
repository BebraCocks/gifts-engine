# 47 · Синяя или красная: «Что дороже?» с Морфеусом

## 1. Сюжет

**Задача автора (чат 2026-11-13).** Формат «Что дороже?»: Морфеус (только голова и ладони) держит в левой ладони
NFT-подарок с синим ореолом, в правой — вещь из жизни с красным ореолом. Фон белый, на нём едва видимые бегущие 0/1.
В начале он собирается из зелёных строк кода (~2 с, с зажатыми кулаками). Пары — максимально разные предметы.
Длина ролика = длина трека автора (Rob Dougan «Clubbed To Death», 58,37 с) вместе с RubUp. Морфеус серьёзный,
никаких гэгов над ним и прилётов в голову; детали ролика-референса на белом фоне не копировать.

**Мысль (v2, автор 2026-11-13).** Пять раундов «серьёзный NFT против вещи из жизни» (вещи выбрал автор). Хук с кадра 0 —
финальная пара: «Кепка Дурова или бензопила? Одна дороже вдвое». Перед финалом 2:2, финал решает.

**Длительность.** До 70 с с RubUp (автор): 63,85 с содержания + RubUp 6,12 с = 69,97 с. Трек автора удлинён до
содержания (повтор двух тактов, `music.py`). RubUp — после 3-го раунда.

**Таймер — настоящий** (автор): вопрос → полные 5 с отсчёта 5…1 (тик каждую секунду) → ответ. Во время отсчёта по
очереди, по одному разу: трюк NFT, потом трюк вещи; короткая фраза Морфеуса — сразу после «5».

## 2. Визуальная концепция

- **Фон.** Белый (`#FFFFFF` с лёгким тёплым-серым к краям не делаем — плоский белый). Бегущие столбцы 0/1 серым
  с прозрачностью ≈ 7 % (`matrix.rain_bg`), разная скорость по столбцам; на хуке и в переходах — зелёные потоки.
- **Морфеус.** Только голова (≈ 430 px шириной, центр x 540, y 690) и ладони (≈ 400 px, x 268 / 812, y 1205).
  Фото автора + спрайты Fish (6 выражений, 6 поз ладони + зеркало). Движение кодом: «дыхание», кивок, наклон,
  блик по очкам, пружинная смена выражения/позы (`character.py`). Выражения сдержанные: спокойный по умолчанию,
  наклон и «нахмурился» на вопросах, ухмылка — когда побеждает телега, очки вниз — только на ответе финала.
  Выражение «морщится» не используется.
- **Ореолы.** Левая ладонь — синий, правая — красный: мягкое радиальное свечение за предметом + тонкая «таблеточная»
  кайма; у победителя ореол разгорается, у проигравшего гаснет.
- **Предметы.** NFT — живой Lottie из `gifts_api`/`lottie.py`, полный цикл. Вещи — вырезанные фото «Детского мира»
  (санки и велосипед — кадры без надписей или вырезка без инфографики; ёлка — вырезка из интерьерного кадра).
- **Типографика.** Моноширинный терминальный шрифт для системных строк (таймер, счёт, лог) зелёным `#00A651`;
  SF Pro Heavy для заголовка «ЧТО ДОРОЖЕ?», цен и подписей (чёрный текст на белом). Цена — плашка синяя/красная.
- **Своё, а не референс.** Нет ценников-капсул внизу, нет прилётов в голову, нет вопросительных знаков над головой.
  Таймер — строка терминала у ладоней; счёт — строка лога вверху `> ТЕЛЕГА 1 : 0 ЖИЗНЬ`; проигравший предмет
  «удаляется из системы» — рассыпается на зелёные 0/1 и стекает вниз.

Общие события — в `events.py`; одни времена для картинки и звука.
Lottie — полный прямой цикл по его реальному FPS, без пинг-понга.
RubUp — в центре, целиком со звуком, основной таймлайн на паузе.
