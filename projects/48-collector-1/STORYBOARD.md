# Новый ролик

## 1. Сюжет

Тема, зритель, длительность, проверяемая главная мысль, источники и дата данных.
Хук → раскрытие по шагам → смысловая пауза с RubUp → ответ → завершение.
Это рабочая структура: конкретный сюжет определяет новый автор.
Записать все реплики, факты, неизвестные значения и место рекламы.

## 2. Визуальная концепция

Новый автор задаёт свои референсы, палитру, материалы, композицию и типографику.
Зафиксировать, что взято из каждого доступного референса, и собственное решение.
Маскот, музыка, облака, обложки, 3D и зацикливание — по задаче, не предустановлены.
Настроить `config.py`, затем поставить `STYLE_READY = True`.

## 3. Цепочка анимаций

| Время / слово | Главный объект и действие | Вход и выход | Текст / камера | Проверка |
|---|---|---|---|---|
| Заполнить | Заполнить | Заполнить | Заполнить | Читаемость и стыки |

Общие события — в `events.py`; одни времена для картинки и звука.
Lottie — полный прямой цикл по его реальному FPS, без пинг-понга.
RubUp — в центре, целиком со звуком, основной таймлайн на паузе.

## 4. Звук

Голос: новый Fish Audio ключ и новый выбранный голос либо без дикторской озвучки.
До добавления ключа продолжать с текстом и явно сообщать об отсутствии диктора.
Звук рекламного баннера сохраняется в любом режиме.
SFX — пак по умолчанию `input/sfx/` через `sfxkit` (см. `docs/SFX.md`): для каждого
акцента запишите действие → роль → время/выравнивание; мотивы с `key=` перечислите отдельно.
Музыка — по задаче, в комплекте её нет.
Вместе с хайлайтами автор получает `build/review/sfx_only.mp3`, `mix.mp3`, `sfx_cues.txt`.
