# 49-mita-monochrome · Мита объясняет монохром

## 1. Сюжет

Тема: почему одинаковые подарки стоят по-разному — монохромы. Ведущая — Мита (MiSide), арты
автора. Зритель — владельцы и покупатели NFT-подарков Telegram. Длительность ≈ 60 с без рекламы,
RubUp ≈ на 28 с, перед чёрно-белым монохромом. Цифры (%, ₽) не из памяти: редкость —
api.changes.tg, цены — маркет, с датой.

Карточка подарка (без озвучки): сверху название коллекции, ниже анимация, затем
«Модель · %», «Фон · %», «≈ N ₽». Узор не пишем. Мита внизу сбоку, не закрывает цифры.

Не проверено: подарки для хука, вида 1 и вида 3; все % и цены.

## 2. Визуальная концепция

Арты Миты — `input/mita/` (9 фигур, рот закрыт, прозрачный фон; `reference.png` — исходник
автора, `sheets/` — листы ChatGPT). Листы 2 и 3 пришли с нарисованной шахматкой; через Fish nano-banana
(2×1350 кредитов, 15.11.2026) шахматка заменена на #00FF00 (`sheets/*_green.jpg`), затем хромакей
с подавлением зелёного по краю (свитер в листе 3 сохранён); на тёмном фоне проверено. Фигуры из
листов 2–3 ≈1670 px в высоту, из листа 1 ≈1000 px — масштабировать к одной высоте. У bw_proud
после правки улыбка с приоткрытым ртом.
Кружение (на «наряды»): normal_explain → spin_1…spin_4 → зеркальные spin_3, spin_2, spin_1 → normal_explain.
Лист кружения: юбка на кадрах 2–3 опущена через Fish nano-banana (1350 кредитов), чтобы не было видно белья/ягодиц. Палитра, фон и типографика — предстоит выбрать.
